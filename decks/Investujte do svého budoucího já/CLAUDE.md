# Project instructions

## Never use em dashes
No em dash (`—`, `&mdash;`) in any content, in any file, in any language: slide copy,
speaker notes, citations, list items, chat replies.

Use instead, in this order of preference:
1. Recast the sentence so no dash is needed.
2. A comma, colon, or full stop.
3. An en dash with spaces (` – `) only where Czech typography calls for it.

En dashes are allowed **only** inside numeric ranges with no spaces: `1,2–1,6 g/kg`, `Den 1–5`, `75–80 %`.

## Deck conventions (Vogue deck)
Certainty is marked with the five-tick ladder plus a mono label (e.g. `Kohortová studie`),
never the A/B/C/P letters. Footer page numbers run 01 upward with no gaps.
Photographs are duotoned violet from `assets/duo/`; no natural-colour stock, no app mockups,
no journal screenshots.

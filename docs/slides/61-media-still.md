**SPLIT** · 61 · Media still

**Use when**
Showing a video or external artefact.

**Roles**
- claim — 2 lines, ≤70 chars
- body — evidence, 32px floor
- label — mono, tracked caps
- data — mono, tabular
- photograph — duotone in Public mode

**Rules**
- Play mark is a mark, not a screenshot of a player.
- Description and source left; the still is duotoned unless it is Clinical.
- Text column starts at x 120, the photograph at x 1200. Nothing invents another x.
- If the photograph is not the evidence, drop it and use OPEN.

**SPLIT** · 09 · Comparison

**Use when**
Two options or two regimes compared.

**Roles**
- claim — 2 lines, ≤70 chars
- sub — column head, 40px/500
- body — evidence, 32px floor

**Rules**
- Same number of rows on both sides, same order, same scale.
- The preferred side is not marked by colour alone.
- Text column starts at x 120, the photograph at x 1200. Nothing invents another x.
- If the photograph is not the evidence, drop it and use OPEN.

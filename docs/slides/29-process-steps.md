**STACK** · 29 · Process steps

**Use when**
A procedure that happens in order.

**Roles**
- claim — 2 lines, ≤70 chars
- sub — column head, 40px/500
- figure — Geist 300 + mono unit
- body — evidence, 32px floor

**Rules**
- Numbered, five steps maximum, and the footer scale matches the steps.
- If the steps are not sequential, this is the wrong layout.
- Never run three STACK boards in a row — split the argument or draw the relationship.
- Five items maximum in a list, three in a column set. Over that, it is a handout.

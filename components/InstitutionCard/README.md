An organisation that corroborates the record. Always links out.

```jsx
<InstitutionCard name="Instituce, oficiální název" role="Role jednou větou." url="https://…" />
```

`name` is the organisation's own registered name, in full, never abbreviated on first use and never translated inside Czech material. `url` is required by design: a card with no link is a fabricated citation. The institution is drawn as the `building` mark, never shown as a photograph of a building.

One 24px-grid, 1.5px-stroke icon set: eight topic marks and nine interface marks, the site's only glyph source.

```jsx
<Icon name="arrow" size={19} />
<span className="mark"><Icon name="zenske-zdravi" size={26} /></span>
```

Topic names: `prehled` `medicina` `zenske-zdravi` `dlouhovekost` `spanek` `fitness` `vyziva` `lifestyle`.
Interface: `arrow` `phone` `mail` `instagram` `menu` `close` `building` `external` `plus`.

Colour is `currentColor`. Never pair a topic mark with colour alone — the topic's name is always beside it in text. Do not substitute emoji, a glyph font, or a Lucide/Heroicon lookalike; this set is the whole vocabulary.

The evidence ladder: five ticks and the study design in mono, marking how well a claim is supported.

```jsx
<Grade level="kohorta" />
```

Levels: `meta` (5) · `rct` (5) · `kohorta` (4) · `konsenzus` (3) · `mechanismus` (2) · `nepodlozeno` (1).

Six levels is the decided scale (2026-09-13); a deck that never cites consensus simply never shows that rung. She sets the level; it is never inferred from the claim. Use it only where the source states the study design outright. Absence is meaningful — most claims carry no grade, which is what makes presence a signal.

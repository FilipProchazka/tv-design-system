The opening band every inner page shares.

```jsx
<PageHero heading="Tvrzení jako celá věta." lead="Jedna podpůrná věta." icon="zenske-zdravi" />
```

`heading` is written as a claim, not a topic label, wherever the content allows: and when it is already a full sentence, `eyebrow` is dropped, because saying the same thing twice in two type sizes is the duplication this component exists to avoid. `icon` is a topic mark in a 64px white tile, on topic pages only.

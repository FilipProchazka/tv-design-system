# Portion illustration assets

Generated with the built-in image_gen tool for this project on 2026-09-06. Original assets and exact prompts are stored in `output/imagegen/portions-v1/`; the corrected cupped-hand PNG and exact edit prompt are in `output/imagegen/portions-v2/`.

Each WebP embeds its exact generation prompt. All seventeen files were converted with cwebp, quality 88, to 720 × 720 while preserving transparent alpha. The six additional food originals and prompts are in `output/imagegen/portion-examples/`. No source illustration from Precision Nutrition was copied. Its hand-measure method is credited on the page.
